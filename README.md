# Машина Тьюринга

## 📋 Описание
Эта машина Тьюринга предназначена для выполнения операций над символами на ленте, содержащей максимум **20 ячеек**. Текущая версия удаляет все символы **'a'**.

## ⚙️ Как запустить
1. Откройте терминал.  
2. Вставьте следующую команду:  

```bash
build ~3q~a%b%c%X~a%b%c%b%a%a%a%c~X>q1%X>q3%X>q2%b>q2%b>q3%b<q1%c>q3%c>q1%c<q2%X<q3%X>q1%X>q2~
```
3. Нажмите **Enter**
4. Нажмите кнопку **Launch**

Токен настроит машину (таблицу, входное слово и алфавит) на определённый вид работы и кнопка запустит алгоритм
